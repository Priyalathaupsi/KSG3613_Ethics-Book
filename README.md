1. Extract this ZIP.
2. In `Priyalathaupsi/KSG3613_Ethics_Book`, upload `index.html` and `chapter5_wheel.html` at repository root, replacing the old `index.html`.
3. Keep all your existing `book.css`, `book.js`, chapter audio, videos, image files, Chapter 3 game and Chapter 4 escape room in place. Those files were not included in the supplied HTML and therefore are not inside this patch ZIP.
4. Commit changes and refresh the GitHub Pages site.
